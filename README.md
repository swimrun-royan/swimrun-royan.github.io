# SwimRun Cote de Beaute — site officiel

Site de l'edition 2026 du SwimRun Cote de Beaute, organise par le Triath'Club Royannais.

- En ligne : https://swimrun-royan.com
- Hebergement : GitHub Pages (branche `main`, racine du depot)
- Domaine personnalise : fichier `CNAME`

## Structure

- `index.html` — page unique (accueil, presentation, inscription, courses, challenge, partenaires, contact)
- `images/` — visuels du site
- `images/partenaires/` — logos des partenaires

## Ajouter un logo partenaire

Deposer le fichier dans `images/partenaires/` au nom attendu par `index.html`
(voir les balises `<img>` de la section `#partenaires`). Tant que le fichier est
absent, la case affiche le nom du partenaire.

## Ne jamais deposer ici

Aucun mot de passe, code de secours, cle d'API ou document personnel : ce depot
est public et tout son contenu est accessible en ligne.
